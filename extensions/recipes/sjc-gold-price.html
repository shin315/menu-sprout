SJC Gold Price Widget Recipe

Capability

Source real-time SJC gold prices in Vietnam (giá vàng SJC) for a menu-sprout widget.

Use real gold market data only. When real price data is temporarily unreachable, return an explicit unavailable error or retain the last successful snapshot marked stale. Do not fabricate mock numbers or fall back to simulated prices.

Scope: this recipe specifies how to fetch, parse, and normalize live SJC gold rates. The UI should display standard Vietnamese labels (Giá vàng SJC, Mua vào, Bán ra, Chênh lệch) and support standard gold products such as SJC 1L-10L (vàng miếng 9999) and SJC Ring (vàng nhẫn 99.99).

This recipe is self-contained. Do not require external source code, websites, or implementation guides to complete it.

PrioritySourceUse WhenExpected Data

Live API Details and Response Shapes

Endpoint: GET https://www.vang.today/api/prices (or filtered: https://www.vang.today/api/prices?type=SJL1L10)

Request headers: standard Accept: application/json and a descriptive User-Agent.

Value semantics and units:

  • Unit: Prices are in VND per lượng (1 lượng = 1 cây = 10 chỉ = 37.5 grams).
  • Numbers: buy and sell are integer numbers in VND (for example 140500000 represents 140,500,000 VND / lượng or 140.5 triệu VNĐ).
  • Spread: Spread between buy and sell is computed as sell - buy (e.g. 143500000 - 140500000 = 3000000 VND).
  • Key products: SJL1L10 is SJC 1L-10L (vàng miếng 9999), the primary national benchmark. SJ9999 is SJC nhẫn trơn (ring).

Normalized TypeScript Shape

type GoldPriceItem = {
  id: string;              // "sjc-1l-10l", "sjc-ring", "bt-sjc"
  code: string;            // "SJL1L10", "SJ9999", etc.
  name: string;            // "Vàng miếng SJC 9999", "Vàng nhẫn SJC 99.99"
  buy: number;             // in VND (e.g. 140500000)
  sell: number;            // in VND (e.g. 143500000)
  spread: number;          // sell - buy
  changeBuy?: number;
  changeSell?: number;
  currency: "VND";
};

type SjcGoldSnapshot = {
  source: "vang-today";
  items: GoldPriceItem[];
  updatedAt: string;       // ISO timestamp or HH:mm DD/MM/YYYY
  refreshedAt: string;     // ISO timestamp of fetch
  stale: boolean;
};

Implementation Contract

All network fetching and JSON parsing belongs in sjc-gold-price/server.ts behind window.menuSprout.capabilities.invoke("sjc-gold-price", "getGoldPrices", options). Do not call remote HTTP endpoints directly from renderer components.

The renderer widget lives in sjc-gold-price/widget.tsx and sjc-gold-price/components.tsx. It calls the server action on mount and during manual/scheduled refresh, and renders using @menusprout/ui components.

Refresh: export a RefreshableMenuSproutWidget with a 15-minute viewRefreshIntervalMs and a refreshView that calls getGoldPrices; the host also runs refreshView each time the popover opens. 15 minutes is the slowest acceptable visible interval. The source only updates every 5 minutes: if the last-good snapshot in context.db was fetched less than 5 minutes ago, return it instead of calling the API again. Do not add a background task unless the user explicitly asks for price monitoring while the popover is closed.

Durable data: the server action stores one last-good SjcGoldSnapshot in context.db (for example a single-row sjc_gold_price_snapshot table) after every successful fetch and reads it back on failure. Do not rely on module-scope variables for the last-good snapshot or the 5-minute guard; they reset on every code edit and app restart.

Server action response shape:

type SjcGoldResult =
  | { ok: true; data: SjcGoldSnapshot }
  | { ok: false; error: string; sourceTried: string[] };

Before reporting work done, inspect the real live API directly with curl, verify the response parsing with live market numbers, and test the widget in the dev environment.

Error Handling

  • If the live API fails or times out, return the last-good snapshot from context.db marked stale: true when available.
  • If no previous snapshot is available and the live API fails, return { ok: false, error: "SJC gold price unavailable", sourceTried: ["vang-today"] }.
  • Do not show mock numbers or placeholder prices when disconnected. Clearly indicate stale or offline state in the UI.
  • Set a reasonable HTTP request timeout of 8 to 10 seconds to avoid hanging the widget UI.

Security Constraints

  • Keep every network request in sjc-gold-price/server.ts; the renderer only calls window.menuSprout.capabilities.invoke.
  • The source is public and needs no API key, cookie, or account. Never add credentials, tokens, or browser cookies.
  • Store only the normalized SjcGoldSnapshot in context.db, never raw response bodies or request headers.

Acceptance Criteria

  • The extension exposes a getGoldPrices server action in sjc-gold-price/server.ts that fetches live SJC gold rates.
  • The server action queries https://www.vang.today/api/prices as the primary free, no-key JSON source.
  • Parsed data extracts SJC benchmark products (SJL1L10, SJ9999) and computes spread (sell - buy).
  • Prices are correctly typed as integer VND per lượng, and formatted legibly with thousands separators in the UI.
  • The UI uses authentic Vietnamese financial labels: Giá vàng SJC, Mua vào, Bán ra, Chênh lệch.
  • Network failures fall back to last-good stale data or return a clean structured failure without mock numbers.
  • The implementer verifies the finished server action against the live source before reporting done.
