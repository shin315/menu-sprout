VND Exchange Rates Widget Recipe

Capability

Source real-time foreign currency exchange rates against Vietnamese Dong (VND) from Vietcombank for a menu-sprout widget.

Use real bank exchange rate feeds only. When the bank source is unreachable or rate-limited, return an explicit unavailable error or keep the last successful snapshot marked stale. Do not fabricate mock rates.

Scope: this recipe specifies how to fetch, parse, and normalize exchange rate tables from the Joint Stock Commercial Bank for Foreign Trade of Vietnam (Vietcombank). The UI should display authentic Vietnamese banking labels (Tỷ giá Vietcombank, Ngoại tệ, Mua tiền mặt, Mua chuyển khoản, Bán ra) and support major currencies including USD, EUR, JPY, GBP, AUD, SGD, and CNY.

This recipe is self-contained. Do not require external source code, websites, or implementation guides to complete it.

Parsing considerations:

  • Number formatting: Attribute values contain comma thousands separators (e.g. 25,760.00). Parse using parseFloat(value.replace(/,/g, "")).
  • Hyphen values ("-"): Some currencies do not have an over-the-counter cash buy rate (e.g. INR, DKK) and are denoted by a dash "-". Map these to undefined or null rather than NaN.
  • Whitespace trimming: CurrencyName often contains trailing whitespace (e.g. "US DOLLAR "). Trim strings upon extraction.
  • Update timestamp: <DateTime> is US-style M/D/YYYY h:mm:ss AM/PM in Vietnam time (UTC+7) with no zone marker. 10/4/2026 12:29:19 AM means 4 October 2026 at 00:29:19 UTC+7, not 10 April. Parse it month-first into an ISO timestamp with a +07:00 offset, and never display the raw string.

Normalized TypeScript Shape

type ExchangeRateItem = {
  currencyCode: string;    // "USD", "EUR", "JPY", "GBP", etc.
  currencyName: string;    // "US DOLLAR", "EURO", etc.
  buyCash?: number;        // in VND, undefined if cash exchange unavailable
  buyTransfer: number;     // in VND
  sell: number;            // in VND
};

type VndExchangeRatesSnapshot = {
  source: "vietcombank-xml";
  bank: "Vietcombank";
  rates: ExchangeRateItem[];
  updatedAt: string;       // ISO timestamp (+07:00) parsed from <DateTime>
  refreshedAt: string;     // ISO timestamp of client fetch
  stale: boolean;
};

Implementation Contract

All network fetching and XML parsing lives in vnd-exchange-rates/server.ts behind window.menuSprout.capabilities.invoke("vnd-exchange-rates", "getExchangeRates", options). Keep Node and fetch calls in the server action.

The renderer widget lives in vnd-exchange-rates/widget.tsx and vnd-exchange-rates/components.tsx. It calls getExchangeRates and renders popular exchange pairs (USD, EUR, JPY, GBP, CNY, etc.) with a clean searchable or tabbed UI.

Refresh: export a RefreshableMenuSproutWidget with a 30-minute viewRefreshIntervalMs and a refreshView that calls getExchangeRates; the host also runs refreshView each time the popover opens. 30 minutes is the slowest acceptable visible interval. Respect the bank notice of one request every 5 minutes: if the last-good snapshot in context.db was fetched less than 5 minutes ago, return it instead of calling the feed again. Do not add a background task unless the user explicitly asks for rate monitoring while the popover is closed.

Durable data: the server action stores one last-good VndExchangeRatesSnapshot in context.db (for example a single-row vnd_exchange_rates_snapshot table) after every successful fetch and reads it back on failure. Do not rely on module-scope variables for the last-good snapshot or the 5-minute guard; they reset on every code edit and app restart.

Server action response shape:

type ExchangeRatesResult =
  | { ok: true; data: VndExchangeRatesSnapshot }
  | { ok: false; error: string; sourceTried: string[] };

Before reporting work done, inspect the real live Vietcombank XML endpoint directly, verify the parser handles numbers and hyphens accurately, and test the widget in the dev environment.

Error Handling

  • If the network request times out, returns HTTP 4xx/5xx, or cannot be parsed, return the last-good snapshot from context.db marked stale: true when one exists.
  • If no cached snapshot exists, return { ok: false, error: "Vietcombank exchange rates unavailable", sourceTried: ["vietcombank-xml"] }.
  • Never show simulated mock exchange rates when network is unavailable.
  • Set an HTTP request timeout of 10 seconds.

Security Constraints

  • Keep every network request in vnd-exchange-rates/server.ts; the renderer only calls window.menuSprout.capabilities.invoke.
  • The feed is public and needs no API key, cookie, or account. Never add credentials, tokens, or browser cookies.
  • Store only the normalized VndExchangeRatesSnapshot in context.db, never raw response bodies or request headers.

Acceptance Criteria

  • The extension exposes a getExchangeRates server action in vnd-exchange-rates/server.ts.
  • The server action fetches official rates directly from Vietcombank's public endpoint (https://portal.vietcombank.com.vn/Usercontrols/TVPortal.TyGia/pXML.aspx).
  • The parser strips thousands comma separators and maps hyphen ("-") cash rates to undefined.
  • Normalized snapshot contains essential currencies: USD, EUR, JPY, GBP, AUD, SGD, CNY.
  • The UI features authentic Vietnamese banking labels: Tỷ giá Vietcombank, Mua tiền mặt, Mua chuyển khoản, Bán ra.
  • Unreachable bank endpoints return last-good stale data or a structured failure error; no mock rates.
  • The implementer verifies the finished server action against the live Vietcombank feed before reporting done.
